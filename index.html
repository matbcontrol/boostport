Load your Boosts

Arc keeps every Boost as a small folder on your disk. Point Boostport at that folder, check what it found and download the archive. It's free, with no account and no limit.

On a Mac

Your Boosts live here. In the folder picker press Cmd Shift G and paste the path.

~/Library/Application Support/Arc/boosts

On Windows

Arc lives in a package folder whose name starts with TheBrowserCompany.Arc, inside %LOCALAPPDATA%\Packages. Pick that folder and Boostport searches it for Boosts.

Questions

Does anything leave my computer?

No. The page reads the folder inside this tab, builds the archive in memory and hands it to you. Its security policy blocks every network request, so it could not send your Boosts anywhere even if it tried. Turn off Wi-Fi and it still works.

Is it really free?

Yes, for every Boost and as often as you need. There is no server behind this page, so there is nothing to pay for. If it saved your Boosts, you can leave a tip on Ko-fi.

Want a copy that works without internet? Download boostport-offline.zip, unzip it and double-click Boostport.html. It is this same converter in one file.

How do I install what I get?

Dia, Chrome, Edge, Brave: unzip the archive somewhere you will keep it, open the extensions page, switch on Developer mode, choose Load unpacked and pick chromium/my-arc-boosts.

Zen, Firefox: install Violentmonkey or Tampermonkey, then open userscripts/all-boosts.user.js. Safari: the Userscripts app takes the same file.

What doesn't move?

Boosts that restyle Arc's own pages, because no other browser has them, and Easels. If a Boost holds a part Boostport can't read yet, the manifest names it instead of dropping it quietly.

Will my scripts behave the same?

In the extension, yes: Arc ran Boosts as content scripts and so does Chrome. As userscripts they run in the page itself, which covers almost every Boost. Scripts that call chrome.* APIs are flagged and should go through the extension.

Is this made by Arc?

No. Boostport is an independent tool and is not affiliated with The Browser Company. Arc and Dia are their names, used here only to say what this works with.
